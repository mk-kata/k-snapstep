## 4. 全体のデザイン確認

「外部Web担当者の実務ノート」の方向性(白・薄いグレー・チャコール・深い赤・ゴシック体・罫線・ラベル・
余白・控えめな背景色切り替え)は、既存実装ですでに概ね実現されていた。カードの大量使用・強い影・
赤ボタンの連続・派手なアニメーション・和風装飾はいずれも確認されなかった。

今回の確認で、実際のブラウザ表示でしか気づけない次の不具合を発見し、修正した(詳細は6番以降)。

1. ヘッダーのナビが768〜1024px付近で2〜3行に折り返り、窮屈に見える
2. フッターのリンクが`<main>`の外側にあるため、本文用のリンク色ルールが適用されず、ブラウザ既定の
   青色・下線で表示されていた
3. FAQ・ページ内目次の`<summary>`が`display: flex`のため、ブラウザ標準の開閉三角(マーカー)が消え、
   開閉できることが視覚的に分からない状態だった
4. ページ内目次に`open`属性が常時付与されており、「開閉式にしてページ上部を圧迫しない」という設計
   意図に反して常に展開表示されていた
5. 1日WEB担当者・月額Web担当サポートのページ内目次に、記事専用のはずの「この記事の目次」という
   ラベルが表示されていた
6. 1日WEB担当者などの長いページで、セクションの背景色がすべて同じ(白)で、罫線のみで区切られており
   単調に見えた
7. プロフィールページの末尾で、直前のセクションとほぼ同じ文章が2回連続して表示されていた
8. お問い合わせページのformrun埋め込み領域に高さの指定がなく、読み込み前後で0pxに潰れ、フォームが
   ない・壊れているように見える状態だった

## 16. ヘッダー

**発見した不具合と修正**: 通常ナビ5項目(日本語ラベル)+お問い合わせCTAが、768px〜1024px付近で

  ハンバーガーメニューに切り替わるようにした(768pxで発生していた3行折り返しを解消)
- 固定ヘッダーにはしていない(指示どおり)
- スマートフォンメニューの開閉時、最初のナビリンクへフォーカスが移動すること、Escapeキーで閉じられること
  (前回実装の挙動)を再確認した
