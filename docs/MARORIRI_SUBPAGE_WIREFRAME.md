## 1. 下層ページワイヤーフレームの目的

第1段階(`MARORIRI_WIREFRAME.md`)で、共通ヘッダー・共通フッター・共通レイアウトのルール・トップページの配置を設計した。第2段階として、下層ページに共通するレイアウトのルールを整理したうえで、次の3ページを重点的に設計する。

- 1日WEB担当者(全12セクション)

いずれも確定済み本文(仕様書15-2・15-5・15-6)の内容・順序は変更しない。片山まゆみプロフィール・マロリリコーダー部・お問い合わせ・読みもの関連ページ・プライバシーポリシー・404は、次回以降の対象とする(14番参照)。

## 2. 下層ページの共通レイアウト

下層ページは、トップページ(1ページで完結する紹介)と異なり、いずれも「検討中の人が詳細を確認しに来るページ」である。そのため、共通して次の考え方を採用する。

- ファーストビューは簡潔にし、本文へ入りやすい高さにする(3番)。
- CTAは機械的に同じ文言を繰り返さず、ページ末尾はそのページを読んだ人の次の行動に合わせる(4番)。
- 料金・概要情報は、ページごとに異なる表現にせず、共通の表形式で統一する(5番)。
- ページ内目次(アンカーナビ)は、全ページ一律ではなく、必要性に応じて設ける(6番)。

詳細は3〜6番、各ページの個別設計は7〜9番で扱う。

## 3. 共通ファーストビュー

下層ページのファーストビューは、トップページのような大きなビジュアルは使わず、次の要素を簡潔に配置する。

| 要素 | 内容 |
|---|---|
| ページ名(小見出し/レーベル) | 例:「1日WEB担当者」を、確定済みの見出しコピーとは別に、小さな文字でサービス名として上部に添える |
| ページ固有の見出し | 確定済みセクション1の見出しをそのまま使用 |
| 導入本文 | 確定済みセクション1の本文をそのまま使用 |
| CTA | お問い合わせページへ(1日WEB担当者・月額サポートは各ページの確定CTA文言) |
| 料金・概要情報 | 段落内に埋め込まず、短いバッジ(chip)を横に並べて配置する(5番) |
| パンくずリスト | 「トップ ＞ ページ名」を見出しの上に小さく配置し、迷わず後戻りできるようにする |

**サービスページ(1日WEB担当者・月額Web担当サポート)のファーストビューで、見ただけで分かるようにする5点**(誰向けか/何を行うか/単発か継続か/料金/問い合わせへの導線)は、本文+バッジ+CTAの組み合わせで満たす。1文にすべて詰め込まず、要素を分けて配置する。

```text
┌───────────────────────────────────┐
│ トップ ＞ 1日WEB担当者                    │ ← パンくず
│                                       │
│ 1日WEB担当者                            │ ← ページ名(小)
│ 見出し(確定コピー)                        │
│ 導入本文(確定コピー)                       │
│ [55,000円(税込)] [全国オンライン] [WEB担当者メモ+資料1点] [実施後フォロー] │ ← バッジ列
│ [お問い合わせへ] [料金と実施概要を見る]        │
└───────────────────────────────────┘
```

**対応できることページ**は単体の有料サービスではないため、料金バッジは置かず、「状況を確認し、どこへ頼むかまで整理する」という役割が伝わる導入文+CTAのみとする(9番で詳述)。

**デスクトップ/スマートフォン共通の並び順**: パンくず→ページ名→見出し→本文→バッジ→CTA、の縦順は変えない。デスクトップでは全体を中央寄せまたは左寄せのシンプルな1カラムとし、トップページのような左右2分割やイラストは置かない。

## 4. 共通CTA

### ページ内でのCTA配置(3箇所を基本)
1. ファーストビュー内
2. 料金セクションの直後(サービスページのみ)
3. ページ末尾(全ページ共通)

### ページ末尾CTAの使い分け

全ページで同じCTAを機械的に繰り返さず、そのページを読んだ人が次に取りそうな行動に合わせる。

| ページ | 末尾の主CTA | 末尾の補助導線 |
|---|---|---|
| 1日WEB担当者 | お問い合わせへ | 月額Web担当サポートへの導線(確定セクション10) |
| 月額Web担当サポート | お問い合わせへ | 1日WEB担当者との違いへの導線(確定セクション9) |
| 対応できること | お問い合わせへ | プロフィールページへの導線(確定本文のCTA) |

いずれも確定本文にすでに書かれているCTA文言をそのまま使う。ワイヤーフレームとしては「主CTA1つ+補助導線1つ」という配置ルールを統一するにとどめる。

## 5. 料金表示の共通ルール

1日WEB担当者・月額Web担当サポートの料金・概要情報は、同じ2列の表形式(項目/内容)で統一する。すでに確定本文内に「補足要素(概要表)」として存在する形式(仕様書15-2セクション9、15-5セクション8)を、そのままワイヤーフレームの標準表として採用する。

```text
| 項目       | 内容                  |
|-----------|-----------------------|
| 料金       | 55,000円(税込)          |
| 対応方法    | 全国オンライン対応         |
| …         | …                     |
```

**スマートフォンでの表示**: 横スクロールさせず、1行ごとに「項目名(小さいラベル)→内容(値)」を縦に積む形へ変形する。

```text
料金
55,000円(税込)

対応方法
全国オンライン対応
```

「含まれる/含まれないこと」の対比(1日WEB担当者セクション8)も同じ考え方で、デスクトップは2列並び、スマートフォンは「含まれること」→「含まれないこと」の順で縦積みにする。

対応できることページは、単体の料金を持たないため、この表形式は使用しない。

## 6. ページ内ナビゲーションの方針

すべてのページに一律で目次(アンカーナビ)を設けるのではなく、次のように判断する。

| ページ | 目次(アンカーナビ) | 理由 |
|---|---|---|
| 1日WEB担当者 | 設ける | 全12セクションと長く、FAQ・料金など「知りたい箇所だけ読みたい」需要が高い |
| 月額Web担当サポート | 設ける | 全10セクションで、料金・1日WEB担当者との違いへの部分的な参照ニーズがある |
| 対応できること | 設けない | カテゴリを順に読み進める構成で、FAQのような検索的な参照よりも、全体を眺めて自分に近い領域を探す読み方に近いため |

目次を設けるページでは、ファーストビュー直下ではなく、導入(セクション1・2)を読み終えた位置に、簡易なアンカーリスト(例:「1テーマ・1サイトについて」「料金」「よくある質問」等、主要セクションのみ抜粋)を配置する案とする。全セクションを目次に載せると目次自体が長くなるため、主要な参照先のみに絞る。実装方法(開閉式か、常時表示か)は次回判断する(13番)。

## 9. 対応できることページ

確定済み全10セクションの本文・順序は変更しない。

### ファーストビュー(セクション1)
「何でもできる人」ではなく「状況を確認し、どこへ頼むかまで整理する人」として伝わるよう、料金バッジは置かない。トップページ セクション6で使用した「領域が重なる抽象図」と同じモチーフを、ここでも小さく再利用し、サイト全体で一貫した「幅広さ」の視覚表現にする。

| 対象読者の切り分け | ― | ― | ― | ― | 末尾に軽い案内文 | ― |
| ページ末尾の型 | 主CTA+月額サポートへの軽い導線 | 主CTA+1日WEB担当者との違いへの導線 | 主CTA+プロフィールへの導線 | 主CTA1つ+テキストリンク2つ | コーダー部専用CTA+法人向け案内 | フォーム送信のみ(別CTAなし) |

**共通点**: ファーストビューの構成(パンくず・ページ名・見出し・本文・バッジ・CTA)、丸みの強い装飾カードを大量に並べない方針、見出し階層のルールは6ページすべてで共通。

**違い**: 対象読者(事業者向け/コーダー個人向け)によって、コーダー部のみ末尾に「対象読者の案内文」を設ける。プロフィールとお問い合わせは料金要素をほぼ持たず、文章・フォームそれぞれの読みやすさに特化する。

## 20. スマートフォン配置の追加ルール

- プロフィールの写真(またはプレースホルダー)は、テキストの後ろに配置する(他ページの図版と同じ順序ルール)。
- プロフィール「現在の仕事」の3ブロックは縦に積み、大中小の強弱と区切り線は維持する。
- コーダー部の別料金メニューは、価格リストのまま1列で表示し、カード化しない。
- お問い合わせの4ステップは、デスクトップと同じ縦並びのままスマートフォンでも表示する(変形不要)。
- お問い合わせフォームは、12番の共通ルール(項目名→必須任意→入力欄→補足→エラー)をそのまま適用する。
