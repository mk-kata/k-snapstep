既存トップページ(`/`)の文章・構成は一切変更せず、見た目のみ異なる2つのデザイン案を比較用URLで確認できるようにした作業の記録。

## 3. デザインA コンセプト

**「実務ノート・エディトリアル」**

片山まゆみの実務上の判断メモ・整理ノートを、そのまま編集された読み物のように仕立てたデザイン。手書き・文房具的な表現は使わず、実務資料や専門誌のような編集レイアウトを目指した。

## 4. デザインAの特徴

- エディトリアルな余白設計。左寄せでタイポグラフィ中心の構成、見出しは大きめ・本文は落ち着いたサイズで対比をつけた
- 各セクションに小さな番号(`01`〜`08`)とラベルを装飾として付与(`aria-hidden`)
- ヒーローは大見出し+役割ラベル+「確認・整理・判断・伝える」の実務キーワード行+細い罫線+CTAで構成し、右側に「単発/継続」のかかわり方を編集目次のように配置
- 「困りごと」はエディトリアルな目次(index)風のリストで表示
- サービス比較は「A/B」の2ブロックを見開き的に並べる構成
- 相談テーマは2カラムの番号インデックス
- 経歴・プロフィールは小さな見出しラベル(eyebrow)付きの短い記事として表示
- お問い合わせは、落ち着いたあとがき風の中央寄せボックスで締める
- カードを多用せず、罫線とタイポグラフィの強弱で情報を区切っている

## 5. デザインB コンセプト

**「外部Web担当者・進行ボード」**

案件の状況を確認し、判断し、次の担当者へつなぐ「進行ボード」を表現したデザイン。SaaS管理画面的な見た目にはせず、実務で使う整理シート・進行シートを、そのままWebページとして仕立てる方向にした。

## 6. デザインBの特徴

- ヒーロー下に「現在の状況→確認・整理→判断材料→次に行うこと」を、番号+ラベル+罫線で構成した横並びの流れ(単なる矢印の縦並びにはしていない)を配置
- ヒーロー右側は「単発/継続」をステータスチップ風の表示で見せる
- 「困りごと」は番号付きのチェックリスト形式(左に罫線、白背景の帯)
- 「K-SNAPSTEPが行うこと」は上部にアクセント罫線を引いた「進行ボードのタイル」を3列グリッドで表示
- サービス比較は、実際の`<table>`要素による比較表(`<th scope="row">`/`<th scope="col">`)で単発と継続を対比。SaaS的な角丸カードにはしていない
- 相談テーマは「T-01」等のコード風ラベル付きのタグインデックス
- 経歴・確認できる範囲は横帯(セクション背景の切り替え)+実務タグの並びで表現
- お問い合わせは、上部にアクセント罫線を引いた枠で明確に区切った入口パネルとして表示
- 背景色をセクションごとに切り替え、罫線でグループを明確化。角丸・シャドウは使用していない

## 7. 案A・案Bの主な違い

| 観点 | 案A(実務ノート) | 案B(進行ボード) |
|---|---|---|
| ファーストビュー | 見出し+キーワード行+編集目次風サイド | 見出し+ステータスチップ+4段階フローレール |
| 見出しの見せ方 | 大きな対比・余白中心 | ラベル(英字)+見出しの2階層 |
| セクション番号 | `01`〜`08`(装飾ラベルとして) | セクションごとの英字ラベル(CHECK/ROLE/COMPARE等) |
| 困りごとの表示 | エディトリアルな目次リスト | 番号付きチェックリスト(帯+左罫線) |
| K-SNAPSTEPの役割の見せ方 | 3列のラベルグリッド(罫線区切り) | 上部アクセント罫線付きのボードタイル |
| サービス比較 | 見開き2ブロック(文章的) | 実表(`<table>`、単発/継続を対比) |
| 相談テーマ | 番号インデックス(2カラム) | コード付きタグインデックス(`T-01`等) |
| 経歴の紹介 | 記事風(短いプロフィール文) | 横帯+実務タグの並び |
| CTA | 中央寄せの編集後記風ボックス | アクセント罫線で囲んだ明確な入口パネル |
| セクション間のリズム | 白背景中心、余白で区切る | 背景色の切り替え(白/薄グレー)で区切る |

両案とも、K-SNAPSTEPの役割(状況確認・整理・判断材料・伝達・進行確認・実作業・専門家への橋渡し)と、実務経験・落ち着き・相談しやすさ・小規模事業者との近さという共通の方向性は保持している。色は既存の暫定配色(白/`#F5F3F1`/`#242424`/`#666666`/`#D8D3CF`/`#8F2C22`/`#692018`)をそのまま使用し、両案でほぼ共通(意図的に配色差ではなくタイポグラフィ・余白・構造・罫線の使い方で差をつけた)。フォントは指定の日本語ゴシックスタックのみ使用し、Webフォントは追加していない。
